# ClaimBoard

Decentralized insurance claims processing with multi-adjuster approval on Base and Stacks blockchains.

## Features

- File insurance claims
- Multi-adjuster verification
- Approval threshold system
- Evidence documentation
- Automated settlement

## Tech Stack

- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Base**: Solidity 0.8.20, Foundry, Reown wallet
- **Stacks**: Clarity v4, Clarinet, @stacks/connect

## Getting Started

```bash
pnpm install
pnpm dev
```
